# TeleLibrary 

Bot Telegram per l'uso delle rest api di Matthew2077/LibraryTools. Documentero' qui l'organizzazione del programma e la sua evoluzione. 

```
Il bot sara' pienamente utilizzabile a fine sviluppo, per ora e' totalmente in sviluppo, molte cose potrebbero cambiare entro la fine dello sviluppo.
```

## Struttura

```
telelibrary/
├── auth            # Gestione delle sessioni utenti e auth
├── commands        # COmandi del bot
├── libtool-api     # Interazione con REST API di LibraryTools
├── schemas         # Schemas pydantic
├── main.py         # Starta il programma
└── requirements.txt
```
